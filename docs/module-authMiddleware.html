Module: authMiddleware

Módulo que exporta middlewares para autenticación y autorización de usuarios.
Properties:
Name Type Description
authenticate function Verifica que el usuario esté autenticado.
redirectByRole function Redirige según el rol del usuario.
authorizeAdmin function Permite solo acceso a administradores.
onlyUsers function Permite acceso a usuarios y administradores.
onlyAdmins function Permite acceso solo a administradores.
redirectIfAuthenticated function Redirige usuarios autenticados fuera de login/registro.
