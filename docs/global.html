(async) apiFetch(url, methodopt, headeropt, bodyopt) → {Promise.<Object>}

Realiza una petición HTTP genérica al backend y gestiona la respuesta JSON.
Parameters:
Name Type Attributes Default Description
url string URL completa del endpoint al que hacer la petición.
method string <optional>
 "GET" Método HTTP a usar ("GET", "POST", "PUT", "DELETE").
header Object <optional>
 {} Encabezados adicionales a incluir en la petición.
body Object <optional>
 {} Cuerpo de la petición para métodos "POST" o "PUT".
Source:
  • utils/apiFetch.js, line 4
Throws:
- Lanza el JSON de error si el estado no es OK o falla la conexión.
Type
Object
Returns:
- Resuelve con el JSON de la respuesta si el estado es OK.
Type
Promise.<Object>
Examples
// GET sin body
const data = await apiFetch("https://api.example.com/items", "GET", { Authorization: "Bearer token" });
// POST con body
const payload = { name: "Nueva película" };
const result = await apiFetch("https://api.example.com/create", "POST", {}, payload);
