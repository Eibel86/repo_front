(static) apiFetch(url, optionsopt) → {Promise.<Object>}

Función personalizada para realizar peticiones HTTP a APIs externas o internas. Esta función se importa desde un archivo utilitario local y típicamente se utiliza para centralizar el manejo de llamadas a APIs, incluyendo headers, autenticación, etc.
