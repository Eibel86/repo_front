Module: filmsController

Módulo que exporta controladores para la gestión de películas y favoritos de usuario.
Properties:
Name Type Description
films function Renderiza la vista general de películas para usuarios.
getFilmsByTitle function Busca películas por título y muestra resultados.
addFavourite function Añade una película a los favoritos del usuario.
deleteFavourite function Elimina una película de los favoritos del usuario.
favouriteFilms function Muestra la lista de películas favoritas del usuario.
